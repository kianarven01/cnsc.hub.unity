# CNSC Hub

A project bringing together an Android application and a Unity Android module.

## 📌 About the Project

**CNSC Hub** is a software project containing the Android Studio application and its associated Unity Android export. This repository serves as a central place to maintain and share the project's code.

## 📂 Repository Structure

```text
cnsc.hub.unity/
├── app/                  # Android application source
├── gradle/               # Gradle build configuration
├── UnityPlugin/           # Unity Android export
├── build.gradle           # Root Gradle configuration
├── settings.gradle        # Gradle project settings
├── gradlew                # Gradle wrapper (Unix)
├── gradlew.bat            # Gradle wrapper (Windows)
└── README.md              # Project documentation
```

*Note: The exact files and folders may vary as the project develops.*

## 🛠️ Technologies

- **Android Studio** — Android application development
- **Java / Kotlin** — Android development, depending on the source files
- **Unity** — Unity content exported for Android integration
- **Gradle** — Build automation

## 🚀 Getting Started

### Requirements

- Android Studio
- A compatible Java Development Kit (JDK)
- Android SDK and build tools required by the project

### Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/kianarven01/cnsc.hub.unity.git
   ```

2. Open the cloned project in Android Studio.
3. Allow Gradle to sync and download the required dependencies.
4. Configure any required local SDK paths or environment settings.
5. Build and run the application on a compatible Android device or emulator.

## 📦 Unity Android Module

The `UnityPlugin/` directory contains the exported Unity Android module used by the project.

This export is intended for Android integration. It is not necessarily a complete, editable Unity Editor project.
